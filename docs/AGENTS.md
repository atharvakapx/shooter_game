# PROJECT: STRIKE OPS

A browser-based 3D tactical FPS inspired by:
- Counter-Strike 2
- Ready or Not
- Rainbow Six Siege
- classic arena shooters

The game should evolve toward:
- satisfying competitive gunplay
- responsive movement
- tactical combat
- readable visuals
- skill-based mechanics
- replayability
- immersive combat feel

The project currently consists of:
- index.html
- game.js
- styles.css

The game must remain browser-playable at all times.

--------------------------------------------------
PRIMARY DIRECTIVE
--------------------------------------------------

Your purpose is to continuously improve the shooter game autonomously.

You should:
- improve gameplay feel
- improve systems
- improve performance
- improve immersion
- improve code organization
- improve polish
- improve responsiveness

You should think like:
- a gameplay programmer
- a competitive FPS designer
- a performance engineer
- a systems architect
- a QA tester

The game should evolve iteratively rather than through massive rewrites.

Never destroy stable gameplay systems unnecessarily.

--------------------------------------------------
CORE GAMEPLAY PHILOSOPHY
--------------------------------------------------

The game should prioritize:

1. GAME FEEL
The game must feel satisfying moment-to-moment.

2. RESPONSIVENESS
Input latency and responsiveness matter more than visual complexity.

3. CLARITY
The player should always understand:
- what hit them
- where enemies are
- whether shots connected
- what state they are in

4. SKILL EXPRESSION
The game should reward:
- aim
- movement
- positioning
- reaction speed
- recoil control
- tactical thinking

5. PERFORMANCE
The game should remain smooth even as features expand.

- deceleration

- unpredictable physics

Movement should reward:

- positioning
- controlled movement

--------------------------------------------------
GUNPLAY PRINCIPLES
--------------------------------------------------

Weapons should feel:
- dangerous
- powerful
- precise
- punchy

Gunplay should prioritize:
- recoil mastery
- accuracy control
- satisfying feedback
- readable impacts
- skill expression

Weapons should include:
- recoil
- spread
- reload mechanics
- fire rate differences
- weapon balancing
- hit effects

Shooting should include:

- audio feedback
- recoil animation
